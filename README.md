# Absalem Aroon — Personal Research & Founder Website

A premium personal website for **Absalem Aroon** — Blockchain & DeFi Researcher, Web3 Strategist, and Founder of Absalex Labs.

## Overview

This website serves as the official public identity platform for Absalem Aroon, designed to communicate authority, credibility, and intellectual depth. The design philosophy prioritizes clarity, typography, spacing, and visual hierarchy over flashy effects.

## Features

- **Two-Column Layout** — Professional profile sidebar with dynamic content area
- **Single-Screen Homepage** — Elegant, focused landing without excessive scrolling
- **About Section** — Detailed biography, research philosophy, and areas of expertise
- **Research Section** — Premium research cards with categories and publication dates
- **Projects Section** — Showcase of ventures including Absalex Labs
- **Certificates Section** — Visual credential cards with verification links
- **Writing Section** — Essays and publications with search functionality
- **Contact Section** — Professional contact form with social links

## Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS 4
- **Typography:** Inter + Geist Mono
- **Language:** TypeScript

## Design Principles

- Minimal, research-focused aesthetic
- Black and white color scheme with subtle silver-gray accents
- Typography-driven visual hierarchy
- No crypto hype, neon effects, or startup landing page aesthetics
- Professional credibility similar to university researchers and research lab founders

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the website.
